Sunucu Yedek

A personal tool I use to take encrypted backups of my own servers. The name is Turkish for “server backup”.

What it does

  1. Takes the backup. It makes a copy of the server's data on the server itself.
  2. Encrypts it. The copy is encrypted with AES‑256 before it leaves the server. Only the server's owner holds the key.
  3. Stores it. The encrypted file is uploaded to a folder that the tool itself created in the owner's Google Drive. Backups past their retention period are deleted.

Google Drive access

The tool connects to Google Drive with the drive.file scope only. With it, the tool can see only the files and folders it created; it cannot see, read or change anything else in Drive.

Data received from Google is not transferred elsewhere, not sold and not used for advertising. The details are in the privacy policy.

Who it is for

The tool is used only on its owner's own servers. It is not a public service: there are no accounts and no other users.
