Privacy Policy

Effective date: 18 October 2026

1. Scope

This policy explains how the Sunucu Yedek tool uses Google user data and what this site collects about its visitors. The tool and the site belong to Özcan Orhan Demirci and are used only for the owner's own servers.

2. Google data accessed

The tool connects to a Google account with the https://www.googleapis.com/auth/drive.file scope only. With this scope it can access only the files and folders it created in Google Drive: the backup folder and the encrypted backup files in it.

It does not access any other files in Drive, email, contacts, calendar or profile information.

3. How the data is used

The access is used only to:

  • upload encrypted backup files to Drive,
  • download those files when a restore is needed,
  • delete backups whose retention period has ended.

4. Storage and security

Backups stay in the owner's own Google Drive account. Only their encrypted form is uploaded; the encryption key is held only by the server's owner and is never shared with Google.

The tool's access grant (OAuth token) is kept only on the owner's server, in a file with restricted access. Backups whose retention period has ended are permanently deleted from Drive.

5. Sharing

Data received from Google is not shared with any third party, not sold and not used for advertising.

Sunucu Yedek's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Removing access

The tool's access can be removed at any time from the third-party connections page of the Google account. Once removed, the tool can no longer reach Drive; backups uploaded earlier stay in Drive and can be deleted by hand.

7. This site

This site uses no cookies, analytics or tracking, has no forms and collects no personal information from visitors.

The site is hosted on GitHub Pages. GitHub may log technical information such as visitors' IP addresses for security purposes; those logs are covered by the GitHub General Privacy Statement.

8. Changes

If this policy changes, this page is updated and its effective date changes. Earlier versions can be seen in this site's GitHub repository.

9. Contact

Questions about this policy and security reports can be sent privately through the Security tab of this site's GitHub repository.
